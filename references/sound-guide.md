# 声音：从故事里的"听得见什么"来

**铁律：不许用固定预设。**
旧版 `make_audio.py` 只有 calm/warm/misty 三套预设，每套都带**溪水 + 蟋蟀**。
结果不管什么故事，成片里都有河、都有夏虫 —— 声音也会套模板。

现在的做法：`film.json` 里写一份**声音表**，逐场列出"这一场听得见什么"，
`make_audio.py` 按表逐层合成。没写进表里的声音，一个都不会出现。

## 1. 怎么写

```json
"sound": {
  "music": { "amp": 0.050, "density": 0.85, "mood": "warm",
             "scenes": { "s5": 0.45, "s8": 0.7 } },
  "scenes": {
    "s1": [["wind", 0.85], ["leaves", 0.75], ["chestnut", 0.55], ["birds", 0.35]],
    "s5": [["roomtone", 0.80], ["rain", 0.85], ["drips", 0.60], ["straw", 0.30]]
  }
}
```

- 第二项是这一层的音量（0–1），不是绝对电平，混完统一归一化。
- 没写 `scenes` 的场次会退到兜底（只有 `wind` + `leaves`），**不会自动加水声和虫鸣**。
- `music.scenes` 可以逐场压低八音盒（雨大的那场退到 0.45）。

## 2. 可用的声音层

| 名字 | 是什么 | 什么时候用 |
| --- | --- | --- |
| `wind` | 秋风：低频呼啸 + 慢阵风（一阵一阵） | 户外，几乎总要有 |
| `leaves` | 落叶窸窣：高频颗粒，干叶子是脆的 | 秋天、树下 |
| `grass` | 草叶摩擦，比落叶更闷更连续 | 草地 |
| `chestnut` | 栗子落地"啪嗒"：木质短促带空腔 | 有果子掉的故事（这是这类故事的招牌音） |
| `rain` | 雨：宽频噪声 + 密集雨点 | 下雨 |
| `drips` | 滴水"嘀嗒"，音高快速下坠 | 雨后、洞里、石头旁 |
| `roomtone` | 洞里/屋里的低频空间感 | 室内（一加就有"在里面"的感觉） |
| `straw` | 干草窸窣，极轻的高频碎响 | 草垫、窝 |
| `dig` | 挖土的低闷撞击，几下就停 | 鼹鼠、地洞 |
| `steps` | 小脚步"嗒、嗒"，一串一串 | 角色走动 |
| `snow` | 落雪：雪是吸声的，一层很细的高频空气声 + 极稀疏的雪粒沙沙 | **有雪**（别拿 rain 顶，雨的颗粒密得多） |
| `flame` | 灯火的"呼"：低频轻微起伏 + 偶尔一声很轻的噼啪 | 有烛火/油灯/马灯，且灯是这一场的主角 |
| `birds` | 远处鸟叫，偶尔两声 | 白天户外 |
| `stream` | 溪水 | **只在故事里真有水时用** |
| `crickets` | 蟋蟀 | **只在夏夜、故事里真有虫时用** |

## 3. 怎么选（看故事，不看情绪标签）

把每一场过一遍，问三个问题：

1. **这一场在哪里？** 户外 → wind；洞里/屋里 → roomtone（+ 一点漏进来的 wind）。
2. **这一场有什么在响？** 雨、落叶、干草、挖土、脚步、果子落地 —— 只挑故事里真的写了或必然有的。
3. **这一场该安静吗？** 情绪低点（舍不得、想哭）就把层数减到 1–2 层，把 `music` 压到 0.4–0.6。
   不要每场都塞满。

**季节和时辰会否决一些层**：秋天没有蟋蟀；冬天没有落叶；室内没有风（只有 roomtone + 漏进来的风）。

## 4. 例：小刺猬的最后一颗栗子

| 场 | 内容 | 声音 |
| --- | --- | --- |
| s1 | 秋日树下，栗子啪嗒落地 | wind · leaves · chestnut · birds · grass |
| s2 | 洞里捡栗子 | roomtone · straw · wind(远) · leaves(远) |
| s3 | 蓬蓬来 | wind · leaves · grass · steps |
| s4 | 鼹鼠从土里钻出来 | wind · **dig** · leaves · grass |
| s5 | 秋雨夜 | roomtone · **rain** · **drips** · straw（music 退到 0.45） |
| s6 | 雨停，栗子滚进月光 | wind · drips(余滴) · roomtone · chestnut |
| s7 | 天亮 | **birds** · wind · leaves · straw |
| s8 | 夜里搬果子、睡着 | wind · leaves · **chestnut** · roomtone · straw（music 0.7） |

对照旧版：这些场次里有五场原本都在放溪水和蟋蟀，故事里根本没有河，秋天也没有蟋蟀。

## 5. 例：小獾的一盏小灯（冬夜）

| 场 | 内容 | 声音 |
| --- | --- | --- |
| s1 | 雪后白天，山坡洞口 | wind(轻) · **snow** |
| s2 | 洞里，铜灯 | roomtone · straw · **flame** |
| s3 | 黄昏，朋友们来叫 | wind · snow · steps(远) |
| s4 | 夜里出门，风把火苗吹歪 | wind(大) · steps · snow · flame |
| s5 | 灯灭了，什么都看不见 | wind(很轻) · snow(很轻) —— **只留两层**，让旁白扛 |
| s6–s7 | 马灯转出来 | wind · steps · **flame** · snow |
| s8 | 并排走 | wind · steps · flame · snow |
| s9 | 灯会 | wind · flame(很多盏) · snow |
| s10 | 提灯回家 | wind · steps · flame · snow |

冬天没有落叶，所以全片没有 `leaves`；故事里没有河、没有虫，所以没有 `stream` / `crickets`。
