# 配色：只能用 handraw-style 的 C-01–C-36

**铁律：`film.json` 的 palette 里不许出现 `#rrggbb`。**
所有颜色都写色号（`"C-34"`），由 `build_film.py` 在构建时解析成 hex。
`build_film.py --strict-palette` 会在发现自定义色时直接退出。

理由：颜色一旦是手写的 hex，就会不自觉地滑回"深蓝 + 粉笔白"那套默认值，
片子越做越像模板。色号是**受限选择**，逼着你在 36 色里做取舍。

## 0. 技能不在就先装

```bash
git clone https://github.com/yang0/handraw-style ~/.workbuddy-ai/skills/handraw-style
# 或者对助手说：帮我安装这个 Skill：https://github.com/yang0/handraw-style
```

装好后 `python3 scripts/color_lib.py --refresh` 重新采样色卡，刷新 `references/colors.json`。
色卡图（`images/colors/C-xx.webp`）是 hex 的唯一事实来源，**不要凭记忆写色值**。

## 2. 怎么挑（不是查表，是想清楚三件事）

1. **这个故事的"纸"是什么颜色？** 白天/温暖 → C-34 奶油白、C-30 象牙白；
   夜/水边 → C-03 普鲁士蓝；阴雨 → C-35 石板灰；雪/雾 → C-33 暖灰。
2. **主角的剪影靠什么色压住？** 一般用 C-32 炭黑；纸浅时它自己就够黑，纸深时要靠 C-25 的亮边。
3. **全片只有一个"最亮/最饱和"的色，只给光。** 通常 C-25 爱马仕橙（烛光/栗子缝/月亮反光）。
   大地色（C-29/C-36/C-28）不算"光"，可以大面积用。

同一个故事要走过白天到夜里，就**按场次给不同色板**（见 §3），不要全片一份。

## 3. film.json 里怎么写

```json
"palette": { "night": "C-34", "ink": "C-32", "lamp": "C-25", ... },   // 兜底
"scenes": [
  { "id": "s1", "palette": { "night": "C-34", "nightSoft": "C-30", ... },
    "captions": { "style": "dark-text" }, ... },
  { "id": "s5", "palette": { "night": "C-03", ... }, "captions": { "style": "light-text" }, ... }
]
```

`scene.palette` 会盖在 `film.palette` 上，逐场解析。场景里的图层参数（`colour`/`grad`/`outside`…）
同样可以直接写色号，`build_film.py` 会递归解析整份 spec。

## 4. 槽位对照（world.js 会读的 key）

| key | 用在哪 |
| --- | --- |
| `night` | 场景底纸、天空 |
| `nightSoft` | 天空上层的亮带 |
| `ink` | 剪影 |
| `chalk` | 粉笔/线条/雨丝/星 |
| `lamp` | **唯一光色**（光晕、栗子缝、片名、落款） |
| `bank` | 近处地面（`ground` 的兜底色） |
| `soil` / `soilDeep` | 土丘、洞壁 / 更深处、顶边线 |
| `hole` | 拱门里的黑 |
| `stone` / `stoneLit` | 石头 / 石头受光面 |
| `trunk` / `crown` / `crownB` / `leafDry` | 树干 / 树冠 / 树冠亮部 / 垂叶 |
| `leafFallA/B/C` | 飘落的叶子三档 |
| `burr` / `burrLight` | 栗子刺球 / 刺尖 |
| `chest` | 栗子壳 |
| `bladeA/B/C` | 草叶三档 |
| `shadow` | 角色与道具的落地影（浅纸上要用暖影，别用近黑） |
| `patchA` / `patchB` | 地面斑块 |
| `moon` / `dawn` | 月亮 / 天光 |
| `stem` / `leaf` / `plume` | 芦苇（水系场景） |

## 5. 字幕颜色跟着场次走

一条字幕色不可能同时适配奶油白和普鲁士蓝。每场写：

```json
"captions": { "style": "dark-text" }    // 浅底：深字 + 浅托底
"captions": { "style": "light-text" }   // 深底：浅字 + 深托底
```

`build_film.py` 会按"这一句落在哪一场"逐条注入颜色和托底贴图（`cap-halo.png` / `cap-halo-light.png`）。
