# 画风与配色：故事 → 画面

原则（先读）：**大面积剪影 + 少量清晰形状 + 全片唯一暖色只给"光"**。
画面好不好，八成取决于"哪里最亮"，不取决于细节多不多。

## 1. 先定情绪，再定色板

| 故事情绪 | 色板基调 | 参考画风（handraw-style） |
| --- | --- | --- |
| 夜晚 / 睡前 / 温柔 | 深蓝卡纸 + 奶油白粉笔线 + 奶油黄点缀 | FB-029 儿童蜡笔手绘绘本 |
| 温暖 / 陪伴 / 家 | 米黄纸 + 暖褐 + 橘黄 | FB-021 复古暖调绘本 |
| 迷路 / 寻找 / 微光 | 蓝灰 + 雾青 + 一点暖 | FB-032 极简氛围绘本 |
| 白天 / 田园 / 活泼 | 草绿 + 奶油 + 天蓝 | FB-033 森系儿童插画 |
| 冬 / 雪 / 安静 | 蓝灰 + 银白 + 暖黄灯 | FB-047 诗意铅笔与水粉 |

默认色板（film.json 的 palette，夜色自然场景）：

```
night #16233a   卡纸底        nightSoft #1d2d49  天空上层的亮带
ink   #0a1220   剪影线        chalk    #f3ead9   粉笔白（光画出来的线）
lamp  #f6c445   唯一暖色（光） bank     #121e2b   近岸
waterDeep #0f1c34  水          waterBand #22385c  水面反光带
stem  #243840   芦苇茎        leaf     #1a2b32   草叶
plume #2b3f42   芦苇穗        crown    #0c2018   树冠
```

改色板只改 film.json 的 `palette`，所有场景跟着变。

## 2. 暖色的三条纪律

1. 全片**只有一个暖色**（lamp）。第二个暖色最多给一个"角色专属"（例：蜗牛壳 #a9714f）。
2. 暖色只出现在：主角的光、同类生物的光、露水、片名。**不给天空、不给地面、不给装饰**。
3. 光不是 glow：三块同心色斑（opacity 0.06/0.10/0.18）+ 米粒实心灯芯，边缘过抖动滤镜。
   "他的光很小"这件事必须**看得出来**。

## 3. 画面元素与故事节拍的对应

| 故事节拍 | 画面手段 |
| --- | --- |
| 开场/世界 | 宽景一条长镜头推进，片名蜡笔"画"出来 |
| 主角登场 | 镜头推到他，他升起（一个小过冲） |
| 情绪低点 | 镜头推近 + 天色变暗（dusk 层）+ 音乐退 |
| 帮助/给予 | 光圈(pool)出现并跟着走，一路的露水被点亮 |
| 高点/仪式 | 抬头，大片光（tree lights 依次点亮） |
| 道理说完 | 两个角色并排，两盏灯同框 |
| 尾声 | 拉到全片最宽，只剩一个暖点在动；落款 |

## 4. 环境层（world.js 支持的 type）

`sky` `stars` `farbank` `water` `ground` `reeds`（far/near）`grassmass` `blades`
`blurmass`（失焦背景，特写用）`leaf`（宽叶平台）`stones` `dandelions` `twig`
`rock`（可带 crack 石缝）`tree`（树冠+灯）`pool`（光圈）`farflies` `dusk`

新环境（室内/雪/海）照 `LAYERS.leaf` 的样子加一个函数：先大剪影，后细节，
 colours 从 palette 取，**不要在层里写死与 palette 无关的颜色**。

## 5. 角色

`firefly`（size 控制大小，grandpa 变体更宽更慢）、`snail`。
要新角色：照 `KIT.snail` 写——身体一块、特征两处、配色进 palette。
动作只有位移/scale/scaleY，**不用 rotation**（SVG 的 pivot 会跑，见 pitfalls）。
